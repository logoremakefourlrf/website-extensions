# LogoRemakeFour Website Extensions

A responsive, static directory for LogoRemakeFour extension concepts. Open `index.html` in a browser or deploy the directory as a static site.

## Pages
- `index.html`: searchable and filterable extension catalog.
- `adblock.html`, `youtube.html`, `google.html`: concept details and safe installation/setup guidance.
- `settings.html`: local English/German preference and illustrative account controls.

## Important scope and privacy notes
The listed AdBlock, AdBlock for YouTube, Control Panel for YouTube, and Google PDF Viewer are directory concepts, not published installable packages. This repository does not block ads, modify YouTube, implement authentication, or connect Firebase. Login, registration, Google/Apple sign-in, and account closure/deletion controls are non-functional examples; no credentials are collected or transmitted. Language choice is stored in browser local storage. Replace the Firebase JSON placeholder only with a project-specific file when building a private Android app, and keep production secrets out of public repositories.

Issue, pull request, and discussion form templates live under `.github/`. Additional XML metadata samples live under `Extensions/` and `Discussion Templates/`.
